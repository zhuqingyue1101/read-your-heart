## 技术备注
- 记忆机制：DeepSeek 分析时全量读档案 → 生成回复时参考 → 同时抽取 `memory_update` → 前端 `mergeProfile` 合并回 localStorage
- 不引入向量库/Mem0/Qdrant：crush 档案数据量小，全量注入 DeepSeek 128K 上下文即可，省掉一整套向量检索依赖
- 向后兼容：旧 session 无 `profile` 字段，`mergeProfile(undefined, ...)` 从空档案开始积累，不崩
- 意图单选设计：原「目标多选 + 风格多选」与固定 6 档位输出在同一维度上冲突，改为单选意图 + 内部多角度输出，前 4 条 type 写角度名而非档位名
- 部署：Vercel Git 集成，push origin/main 自动触发
