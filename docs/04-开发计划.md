# 开发计划

## Phase 划分原则
- 每个 Phase 完成后可独立验证
- 环境变量/API Key 在 Phase 1 就配置好
- 安全约束从第一天就遵守

---

## Phase 1: 项目骨架 + 后端 OCR + DeepSeek 对接

**目标**: 能上传1张截图 → 后端OCR提取文本 → DeepSeek分析 → 返回JSON结果

**任务**:
- [x] 初始化 frontend (Vite + React + TS + Tailwind)
- [x] 初始化 backend (FastAPI + EasyOCR)
- [x] 配置 DEEPSEEK_API_KEY 环境变量
- [x] 实现 POST /api/analyze（OCR + DeepSeek prompt + JSON解析）
- [x] 前端最简上传页 + 结果展示页
- [x] 验证端到端流程

**验收**:
- 上传1张微信聊天截图 → 看到结果JSON中的结论、回复

---

## Phase 2: 完整分析链路

**目标**: 支持1-5张图、上下文选择、完整输出

**任务**:
- [x] 前端上传1-5张图，预览/删除/排序
- [x] 上下文选择页（关系阶段多选 + 意图单选）
- [x] DeepSeek prompt 优化（含 few-shot 示例）
- [x] 读心结果页完整渲染（结论 + 军师思考）
- [x] 回复建议页（4贴合+2兜底回复卡片 + 复制）
- [x] 翻车预警模块
- [x] 气泡识别错误手动切换

**验收**:
- 完整走通：选择截图 → 选上下文 → 看结果 → 复制回复

---

## Phase 3: 本地存储 + 连续关系感

**目标**: localStorage 档案 + 继续分析

**任务**:
- [x] crush档案 CRUD（创建、选择、编辑、删除）
- [x] 每次分析自动更新档案 summary
- [x] 继续分析流程（基于档案历史 + 新截图）
- [x] 历史记录详情页
- [x] 数据清除功能

**验收**:
- 创建crush档案 → 分析 → 刷新页面档案仍在 → 继续分析有上下文

---

## Phase 4: 优化打磨

**目标**: 体验完善，准备发布

**任务**:
- [x] 加载骨架屏 + 有趣 loading 文案
- [x] 错误处理完善（OCR失败、API异常、网络超时）
- [x] 移动端适配打磨（触摸体验、安全区域）
- [x] 图片压缩（前端 Canvas 压缩后上传）
- [x] OCR 准确率优化（图片预处理）
- [x] 隐私提示完整展示

**验收**:
- 首次用户30秒内完成操作
- 所有异常场景有友好提示
- 回复自然度盲测通过

---

## Phase 5: 部署上线

**目标**: 免费平台部署，面试 demo 稳定可访问

**任务**:
- [x] 后端从 Python FastAPI 迁移为 Vercel Node Serverless Function
- [x] OCR 从 EasyOCR 迁移为 SiliconFlow Qwen3-VL-8B 视觉模型
- [x] 前端图片压缩（Canvas 长边 2048px / JPEG 0.75）+ JSON 上传
- [x] 上下文选择改多选（最多 3 个）+ 自定义输入
- [x] 部署 Vercel 全栈（前端 + Node Function，无需信用卡）
- [x] 新增个人介绍网页 personal-site/
- [x] 新增 crush 档案记忆（结构化档案 + 自动抽取 + 可编辑）
- [x] 回复意图改单选 + 输出改 4 贴合 + 2 兜底

**验收**:
- 线上端到端流程（新建会话 → 上传 → 结果 → 复制 → 接着读）全程无报错
