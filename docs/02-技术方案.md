# 技术方案

## 整体架构

```
用户浏览器 (H5)                  Vercel Serverless Function          AI 服务
┌──────────────┐    JSON       ┌────────────────────────┐      ┌─────────────────┐
│  React SPA   │──(base64图片)─▶│  frontend/api/        │─────▶│ SiliconFlow     │
│  (Vite)      │               │  analyze.js (Node)    │      │ Qwen3-VL (读图) │
│  localStorage│               │                       │      └─────────────────┘
│  (会话/档案) │               │                       │───▶ DeepSeek (分析)
└──────────────┘               └───────────────────────┘
```

## 技术选型

### 前端
| 项 | 选择 | 原因 |
|----|------|------|
| 框架 | React 19 + TypeScript | 生态成熟，适合SPA |
| 构建 | Vite | 快速开发体验 |
| 样式 | Tailwind CSS v4 | 快速实现卡片化设计 |
| 路由 | 无路由库 | App 内 phase 状态机（列表/上传/结果/历史/设置/loading） |
| 状态 | React useState + localStorage | 轻量，无需Redux |
| HTTP | fetch API | 零依赖 |
| 图片处理 | Canvas 压缩 | 长边 2048px、JPEG 0.75，适配 Vercel 4.5MB 限制 |
| 存储 | localStorage | 会话/档案，PRD要求 |

### 后端（Vercel Node Serverless Function）
| 项 | 选择 | 原因 |
|----|------|------|
| 运行时 | Vercel Node Function | 免费、免信用卡、与前端同部署 |
| 视觉读图 | SiliconFlow Qwen3-VL-8B | 免费额度、OpenAI 兼容、中文识别好 |
| HTTP | 原生 fetch | 零依赖 |

### AI
| 项 | 选择 | 说明 |
|----|------|------|
| 分析/生成 | deepseek-chat | 用户提供 API Key，纯文本 |
| 图片识别 | Qwen3-VL-8B (SiliconFlow) | 视觉读图，替代原 EasyOCR |

## API 设计

### POST /api/analyze
请求（JSON）：`images`（base64 data URL 数组，1-5张）+ `relationship_stage` + `goal` + `reply_style` + `crush_profile_summary` + `swap_sides`
返回：结论 + 军师思考 + 6条回复建议 + 翻车预警 + 会话摘要 + 档案更新

## 数据流
1. 前端 Canvas 压缩图片 → base64 data URL
2. POST /api/analyze（JSON）→ Node 函数并行调用视觉模型读图（swap_sides=true 时交换左右标注）
3. 合并多图文本 → 构建 prompt（含 crush 档案摘要）→ DeepSeek 分析
4. 解析结构化 JSON → 返回前端渲染
5. 分析后 → localStorage 更新会话：crush_profile_summary 滚动记忆 + 追加一条分析记录（历史）

## 本地存储（localStorage）
- `duxin_sessions`：会话数组，每条含 `records[]`（多轮分析记录）
- `duxin_session_counter`：自动命名计数器
- 不存原始截图，仅存分析文本摘要

## 部署
- Vercel 全栈：Root Directory = `frontend`，`frontend/api/analyze.js` 自动路由到 `/api/analyze`
- 环境变量配置在 Vercel（DEEPSEEK_API_KEY / VISION_API_KEY 等）
- 后端逻辑已从 Python FastAPI 迁移到 Node Function（`backend/` 目录保留，仅供本地参考）

## 安全设计
- API Key 仅存 Vercel 环境变量，不出现在前端代码
- 图片处理完即丢弃，不写磁盘、不持久化
- 前端仅存分析文本摘要，不存原图
