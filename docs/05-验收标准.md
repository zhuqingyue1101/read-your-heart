# 验收标准

> 本文件用于产品上线前逐项验证。每条验收项均为可测试的具体断言，全部勾选即视为达标。

## 验收范围

- 功能验收：上传、分析、回复、会话、历史、设置、纠错
- 非功能验收：性能、兼容性、隐私安全
- 通过门槛：功能验收 100% 通过，非功能验收无阻塞项

---

## A. 上传与图片

- [ ] 支持一次上传 1-5 张聊天截图，格式 jpg / png / webp
- [ ] 单张图片 ≤10MB，超过时给出友好提示而非崩溃
- [ ] 已选图片可预览、可删除单张
- [ ] 已选图片可 ◀▶ 调整顺序，提交后按新顺序送 OCR
- [ ] 选择超过 5 张时提示「一次最多看 5 张，先挑最关键的几张发我」，且只保留前 5 张
- [ ] 未选图片时「开始读心」按钮置灰不可点

## B. 上下文选择

- [ ] 关系阶段 8 选、目标 8 选、回复风格 8 选，默认值分别为「暧昧中 / 试探好感 / 自然一点」
- [ ] 选择结果正确传入后端并影响分析结论

## C. 分析结果

- [ ] 输出一句话结论，以「我觉得 / emmm我觉得 / 我感觉 / 说实话我觉得」之一开头，≤50 字
- [ ] 输出军师思考 ≤200 字
- [ ] 输出 6 条回复（稳妥版 / 暧昧版 / 松弛版 / 幽默版 / 克制版 / 稍微进攻版），每条 5-25 字为主、≤40 字
- [ ] 输出翻车预警（不建议发的话 + 原因）
- [ ] 输出 crush 档案更新（当前状态 / 特征 / 风险 / 摘要）

## D. 回复建议

- [ ] 每条回复可一键复制，复制后按钮反馈「已复制 ✓」

## E. 会话列表

- [ ] 首页为会话列表，空态展示引导 + 新建 CTA
- [ ] 新建会话可填可选备注名，为空自动命名「Crush N」
- [ ] 卡片展示：备注名 + 关系阶段 chip + 上次结论 + 最新状态/特征/风险 + 相对时间
- [ ] 刷新页面后数据仍在（localStorage 持久化）
- [ ] 删除会话需二次确认，删除后列表与 localStorage 同步

## F. 续读分析

- [ ] 结果页「对方回了吗？接着读」回到上传页，阶段/目标/风格/备注名/档案摘要自动带入
- [ ] 续读时显示「📌 正在续读」横幅
- [ ] 只传新截图，旧来龙去脉由档案摘要承接，结论能衔接上文
- [ ] 每次分析后用新的档案摘要覆盖旧摘要（滚动记忆）

## G. 历史记录

- [ ] 列表卡片底部「历史记录（N）」进入详情页，N 为实际记录数
- [ ] 记录按时间倒序，每条可展开查看结论/军师思考/回复/翻车预警
- [ ] 可删除单条记录（二次确认），删除后列表同步
- [ ] 详情页顶部「继续读这条线」可回到续读上传
- [ ] 不存储原始截图，仅存分析文本

## H. 设置页

- [ ] 列表页右上角 ⚙️ 进入设置
- [ ] 可删除单个 crush 档案（含该线全部历史）
- [ ] 可清除全部本地数据（二次确认，不可恢复）
- [ ] 清除后返回空列表，localStorage 同步清空

## I. 气泡识别纠错

- [ ] 结果页底部「气泡识别错了？切换双方重新分析」可见
- [ ] 点击后用原图重新分析并交换左右标注，覆盖上一次结果（不新增历史记录）
- [ ] 可来回切换双方，切换后结论随之更新

## J. loading 与错误处理

- [ ] 分析期间展示骨架屏 + 轮播文案，无白屏
- [ ] OCR 识别失败 / API 异常 / 网络超时均给出友好提示，可回到上传页重试
- [ ] 无图片文本被识别时提示「换一张完整点的截图」

## K. 隐私与安全

- [ ] 截图仅本地识别，不持久化到服务端
- [ ] API Key 仅存后端环境变量，前端代码不含任何 Key
- [ ] 前端仅存分析文本摘要，不存原图
- [ ] 页面可见隐私提示文案

---

## 非功能验收

- [ ] 移动端（375px 宽）布局正常，无横向滚动
- [ ] 按钮可点区域 ≥44px，触摸友好
- [ ] 首次用户 30 秒内完成「上传 → 出结果」
- [ ] 回复自然度盲测通过（不出现 AI 腔 / 客服腔 / 书面语）

## 通过门槛

- 功能验收 A-K 全部通过
- 非功能验收无阻塞项（性能、隐私为硬性要求）
- 端到端流程：新建会话 → 上传 → 结果 → 复制 → 接着读 → 历史 → 设置，全程无报错
