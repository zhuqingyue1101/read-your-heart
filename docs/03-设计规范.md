# 设计规范

## 视觉关键词
- 轻松、暧昧、干净、小红书感、卡片化
- 不要赛博科技感、不要严肃心理咨询感

## 配色方案
| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#FF6B81` | 暧昧粉，按钮/强调 |
| 辅色 | `#FFB8C6` | 浅粉，卡片/背景点缀 |
| 背景 | `#FFF5F5` | 暖白底 |
| 文字主 | `#2D2D2D` | 深灰 |
| 文字辅 | `#8E8E93` | 灰 |
| 警告 | `#FFB020` | 翻车预警/风险提示 |
| 卡片背景 | `#FFFFFF` | 白色卡片 |

## 字体
- 系统默认中文字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 标题：18-22px，加粗
- 正文：15-16px，常规
- 辅助文字：12-13px

## 页面结构（5页 + loading）
1. **会话列表页（首页）** — 所有 crush 关系线卡片（备注名 + 阶段 + 上次结论 + 更新时间）+ 新建会话 + 删除 + 历史入口 + 设置入口
2. **上传页** — 备注名（可选）+ 1-5张缩略图（可排序）+ 上下文选择（阶段/目标/风格）；续读时上下文与档案自动带入
3. **结果页** — 结论 + 军师思考 + 回复建议（可复制）+ 翻车预警 + 「接着读 / 回列表」+ 气泡纠错
4. **历史记录页** — 该条线多轮分析记录（倒序），可展开详情 / 删除单条 / 继续读
5. **设置页** — 删除单个档案 / 清除全部数据
（另有 loading 中间态：骨架屏 + 有趣文案）

## 文案人格
**嘴上很会玩，判断很清醒。**
- 可以说：我觉得这句有点东西 / emmm先别急着原地结婚 / 这球能接，但别跪着接
- 不能说：TA一定喜欢你 / 冷TA三天 / 用这句话拿捏TA / 让TA吃醋

## 交互规则
- 主要流程不超过3次点击选择
- 30秒内完成上传到看到结果
- 移动端优先，触摸友好（按钮≥44px）
- 图片上传支持点击多选（最多5张），可 ◀▶ 调整顺序；超过5张弹提示
- 会话续读：点列表卡片直接进入，无需重选上下文
- 历史记录：列表卡片底部「历史记录（N）」入口
- 设置：列表页右上角 ⚙️ 入口
- 气泡纠错：结果页底部「切换双方重新分析」
- loading状态：骨架屏 + 有趣文案
