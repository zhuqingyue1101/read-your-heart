# 话术招式库（样本分析）

> 基于 `cursh聊天截图/` 132 张小红书真实聊天截图的 OCR 归纳，作为 prompt 优化与后续「招式库」功能的内容底料。

## 一、样本全貌

- 132 张，全部来自小红书（文件名均带「来自小红书网页版」）
- 主题高频分布：暧昧拉扯、打直球、嘴硬、不回消息、心动瞬间、教学帖（"姐只教一次"等）
- 性质：**晒糖 / 教学为主，非求助**；发帖者绝大多数为年轻女性，crush 多为男性
- 关键 gap：样本是"高段位输出方"在炫技，而产品要服务的是"看不懂、不敢回"的求助方（这些帖子的读者）

## 二、招式库（11 招 / 7 类）

| 类 | 招式 | 一句话定义 | 样本原句 |
|----|------|-----------|---------|
| 邀约 | 借口/顺路式 | 用"顺便/路过"降低邀约门槛和需求感 | 「想亲嘴，正好路过你楼下」「或许顺路能路过我这嘛」 |
| 邀约 | 选择题式 | 把"约不约"变二选一，降对方压力 | 「自己去要过两天，陪你的话明天」 |
| 拉扯 | 嘴硬式升温 | 嘴上否认/拒绝，实际在表达关心想念 | 「只是没找你，又不是没想你」「没说陪你吃…自作多情」 |
| 拉扯 | 反向框定 | 把对方普通行为定义成"对我上心" | 「又在跟我报备，我很满意，继续保持」 |
| 试探 | 意图解读 | 把对方的话往"你是不是喜欢我"方向解读 | 「你这么问是不是在意我」「是不是想我了」 |
| 幽默 | 土味反转 | 用一个反转把普通对话变心动瞬间 | 「你随便说个数字…我的人」「你是黑色的，因为我闭上眼全是你」 |
| 幽默 | 谐音梗 | 用谐音制造暧昧双关 | 「你头很圆…我俩很投缘」 |
| 冷落反击 | 反客为主 | 被冷落时不卑微，摆姿态拿回主动权 | 「失败女人的第一步就是期待男人回消息」「谢谢你百忙之中还给我画饼」 |
| 冷落反击 | 幽默反讽 | 夸张调侃点破对方冷落，好笑但不卑 | 「上帝为你关上了哪扇窗，是和我的聊天窗吗」 |
| 游戏化 | 角色扮演 | 用游戏/角色扮演降低推进的心理门槛 | 「先假装我在追你，然后你装高冷」「申请查看好感度，我要攻略你」 |
| 情绪价值 | 日常绑定 | 把日常小事和"你"绑定，制造"我们"感 | 「散步太多，我感觉很暧昧的事」「和你做好像刚刚好」 |

## 三、关键洞察

1. **目标用户画像**：年轻女性为主，crush 多为男性；需求集中在"暧昧期判断 + 怎么回"。
2. **晒糖 vs 求助的 gap**：样本是成功案例/炫技，产品差异化应更强调"清醒判断"（军师），而非"炫技"。
3. **情绪关键词** = "上头 / 爽 / 脸红 / 心动"，产品情绪价值应是"爽"和"心动"，不是严肃分析。
4. **"撤回"是高频暧昧信号**：样本反复出现「撤回了一条消息」「想你了，撤回让我先说」，撤回 = 在意/试探，值得单独处理。
5. **冷落场景是独立主题**：话术以「反讽 / 夺权」为主，而非"体面撤退"，需按冷落程度分级。

## 四、OCR 数据质量问题

批量 OCR 暴露了四类污染，会干扰 AI 分析，已写入 prompt 过滤规则：

- 小红书水印 / 广告 / 推荐卡：「点击头像 无需下载 发送 Good afternoon 即玩」
- 系统提示：「撤回了一条消息」「微信转账」「邀请你语音通话」
- 时间戳 / 日期：「14.35」「17:45」「yesterday」
- OCR 错别字：「擦千手」应为「擦干手」、「味聊夭内容」应为「回味聊天内容」

## 五、已落地到 prompt

- **冷落 / 未回复场景分级**：轻度（给空间/体面收尾）vs 重度（幽默反讽/夺回主动权），守住安全底线（不辱骂、不骚扰、不纠缠）。
- **OCR 噪音过滤**：只有「本人：」「对方：」开头才是真实对话，其余忽略。

## 六、后续方向

- 招式库可作为结果页"回复标签"的升级方向（标签从"稳妥版"换成招式名，附原理+时机）。
- 冷落场景若数据验证为高频独立需求，再考虑显性入口；当前先靠 prompt 行为修正。
